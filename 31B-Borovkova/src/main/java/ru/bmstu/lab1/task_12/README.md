# Задача 12. Пара с заданной суммой

Простое решение — перебор всех пар (i, j) двумя вложенными циклами —
работает за O(n²): при n до 10^5 это до 5·10^9 сравнений, слишком медленно.

Идея быстрого решения: массив проходится справа налево, HashMap хранит
для каждого уже пройденного числа наименьший индекс справа от текущего i,
где оно стоит. Для a[i] партнёр — число s - a[i]; если оно есть в HashMap,
его индекс — наименьший подходящий j. Так как движение идёт влево,
каждая найденная пара имеет меньший i и заменяет предыдущую, поэтому
в конце остаётся пара с наименьшим i (и наименьшим j для этого i).
Элемент добавляется в HashMap после поиска, чтобы не образовать пару
сам с собой. Ключи хранятся в long, так как s - a[i] может выйти за int.

Время: O(n) в среднем — один проход, операции get и put у HashMap
выполняются в среднем за O(1).
Память: O(n) — массив и HashMap (не больше n записей).
