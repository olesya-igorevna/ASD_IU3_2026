# Задача 43. Перемещение нулей в конец

Идея: два указателя в одном массиве. Указатель i просматривает все элементы,
k — сколько ненулевых элементов уже собрано в начале массива.
Каждый ненулевой элемент переписывается на позицию k (k ≤ i, поэтому ещё не
просмотренные элементы не затираются), и k увеличивается. Ненулевые идут в том же
порядке, в каком встречались, — относительный порядок сохраняется.
После прохода позиции k..n−1 заполняются нулями: их ровно столько, сколько нулей
было в массиве. Новый массив не создаётся — модификация на месте.

Время: O(n) — один проход для сбора ненулевых и один для заполнения нулями.
Память: O(n) на сам массив; дополнительно O(1).
