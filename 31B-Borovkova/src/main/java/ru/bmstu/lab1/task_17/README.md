# Задача 17. Сортировка по сумме цифр

Идея: при чтении для каждого числа считается сумма его цифр s[i]
(цифры отделяются через x % 10 и x / 10). Число типа int имеет не больше
10 цифр, поэтому сумма цифр лежит в пределах 0..90 — это маленький диапазон,
и по нему удобно сделать сортировку подсчётом:
1. count[d] — сколько чисел имеют сумму цифр d;
2. start[d] — с какой позиции в ответе начинаются числа с суммой d
   (префиксные суммы массива count);
3. числа раскладываются в ответ в исходном порядке слева направо,
   поэтому при равных суммах исходный порядок сохраняется (сортировка устойчива).
Отрицательные числа по условию недопустимы — на них выводится ошибка.

Время: O(n) — сумма цифр числа считается за O(1) (не больше 10 цифр),
подсчёт и раскладка — O(n + 91) = O(n).
Память: O(n) — исходный массив, суммы цифр и ответ; массивы count и start
имеют постоянный размер 91.
