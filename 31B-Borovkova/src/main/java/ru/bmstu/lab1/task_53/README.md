# Задача 53. Седловые точки

Идея: седловая точка — элемент, минимальный в своей строке и максимальный
в своём столбце. Сначала одним проходом считаются минимумы всех строк
(rowMin) и максимумы всех столбцов (colMax). Затем каждый элемент
проверяется за O(1): он седловой, если равен rowMin своей строки
и colMax своего столбца. Сравнение на равенство находит и точки
при одинаковых значениях. Если седловых точек нет, печатается -1.

Без вспомогательных массивов для каждого элемента пришлось бы заново
просматривать строку и столбец — O(n·m·(n + m)).

Время: O(n·m) — три прохода по матрице (минимумы строк, максимумы
столбцов, проверка элементов).
Память: O(n·m) — матрица; дополнительно O(n + m) на rowMin и colMax.
