# Задача 2. Индекс первого вхождения

Идея: массив сохраняется целиком, так как число x вводится после него.
Затем массив просматривается слева направо до первого элемента, равного x;
поиск прерывается сразу после находки. Если совпадений нет — выводится -1.

Время: O(n) — чтение массива занимает n шагов, поиск в худшем случае ещё n шагов; итого O(n).
Память: O(n) — хранится массив из n элементов.
Так как х вводится после массива мы не можем обойтись без его храниния.
