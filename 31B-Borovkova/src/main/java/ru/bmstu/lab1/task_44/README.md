# Задача 44. Чередование знаков

Идея: элементы раскладываются в два вспомогательных массива — pos (положительные)
и neg (отрицательные) — в том порядке, в каком встречаются в исходном массиве.
Затем исходный массив заполняется заново: на чётные позиции 0, 2, 4, …
по очереди ставятся элементы pos, на нечётные 1, 3, 5, … — элементы neg.
Так массив начинается с положительного, знаки чередуются, а порядок внутри
каждой группы сохраняется.

Проверки ввода по условию: нулей быть не должно, положительных и отрицательных
должно быть поровну (2 · k = n, где k — число положительных); иначе выводится ошибка.

Почему не на месте: стабильная перестановка на месте возможна только сдвигами
(O(n²)) или сложными алгоритмами; условие этого не требует, поэтому выбран
простой линейный вариант с дополнительной памятью.

Время: O(n) — чтение, раскладка и сборка — по одному проходу.
Память: O(n) — исходный массив и два массива по n / 2 элементов.
