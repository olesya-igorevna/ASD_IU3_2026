# Задача 27. Сумма квадратов

Идея: массив не хранится — каждое число сразу возводится в квадрат
и прибавляется к сумме.

Переполнение: квадрат одного числа считается в long — по модулю он не больше
(2^31)^2 = 2^62 < 2^63, это помещается. Но уже сумма двух таких квадратов
(например, для −2147483648 и −2147483648 получается 2^63) выходит за предел long,
а всего сумма может достигать n · 2^62 ≈ 2^79. Поэтому сумма накапливается
в BigInteger. Числа в ней не длиннее ~80 бит, так что одно сложение
выполняется за O(1).

Время: O(n) — на каждый элемент одно умножение в long и одно сложение BigInteger.
Память: O(1) — хранится только сумма (длина её записи ограничена ~80 битами).
