# Задача 36. Бегущая сумма

Идея: s[0] = a[0], а каждый следующий элемент s[i] = s[i − 1] + a[i] —
сумма первых i + 1 элементов получается из уже посчитанной суммы первых i
одним сложением, без повторного суммирования. Исходный массив не хранится:
каждое прочитанное число сразу прибавляется к предыдущей сумме.
Суммы хранятся в long, так как сумма многих int может выйти за предел int
(по модулю она не больше n · 2^31 < 2^48).
Ответ печатается только после чтения всех чисел, чтобы при ошибке ввода
не напечаталась часть результата.

Время: O(n) — одно сложение на элемент.
Память: O(n) — массив сумм (он и есть ответ).
