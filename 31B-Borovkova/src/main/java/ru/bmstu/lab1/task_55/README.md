# Задача 55. Сумма элементов на побочной диагонали

Идея: в строке i побочная диагональ проходит через столбец n - 1 - i
(в строке 0 — последний столбец, далее на каждой строке на один левее).
Поэтому сумма считается одним циклом по строкам, без перебора всех клеток.
Сумма хранится в long, чтобы избежать переполнения int.

Время: O(n²) — чтение матрицы n×n; сам подсчёт суммы занимает O(n).
Память: O(n²) — хранится матрица.
