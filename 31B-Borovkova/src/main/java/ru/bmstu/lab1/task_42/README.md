# Задача 42. Вставка элемента в отсортированный массив

Идея: массив сразу создаётся длины n + 1, последняя ячейка свободна.
1. Бинарным поиском находится позиция l — первый индекс, где a[l] > x
   (если таких нет, l = n). Инвариант поиска: все a[0..l−1] ≤ x, все a[r..n−1] > x;
   отрезок [l, r) на каждом шаге сокращается вдвое. Середина считается как
   l + (r − l) / 2, чтобы сумма индексов не переполнилась.
   При равных элементах x встаёт после них — порядок неубывания при этом сохраняется.
2. Хвост a[l..n−1] сдвигается на одну позицию вправо (с конца, чтобы не затереть
   элементы), и a[l] = x.

При чтении проверяется, что массив неубывающий, — иначе бинарный поиск неприменим.

Время: O(n) в целом. Поиск позиции — O(log n), как требует условие, но сдвиг хвоста
при вставке в массив занимает O(n) в худшем случае (x меньше всех элементов);
чтение и вывод массива — тоже O(n).
Память: O(n) — один массив длины n + 1.
