# Задача 49. Сумма строк матрицы

Идея: заводится массив rowSum из n элементов — по сумме на строку.
Матрица читается по строкам и не хранится: каждый элемент сразу
прибавляется к сумме своей строки. Начальные суммы равны 0
(новый массив в Java заполняется нулями). Суммы хранятся в long,
чтобы избежать переполнения int. Ответ печатается только после
чтения всей матрицы, чтобы при ошибке ввода не напечаталась часть результата.

Время: O(n·m) — каждый элемент читается и прибавляется один раз.
Память: O(n) — хранится только массив сумм строк,
сама матрица не хранится.
