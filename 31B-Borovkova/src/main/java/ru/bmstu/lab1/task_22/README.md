# Задача 22. Сортировка по частоте

Идея:
1. Массив сортируется по возрастанию (Arrays.sort) — равные значения оказываются рядом.
2. Одним проходом собираются группы: значение v[g] и сколько раз оно встретилось f[g].
   Группы получаются уже упорядоченными по возрастанию значения.
3. Группы сортируются по убыванию частоты сортировкой подсчётом: частота лежит
   в пределах 1..n, count[c] — число групп с частотой c, start[c] — позиция,
   с которой начинаются группы частоты c (для убывания позиции считаются от c = n вниз).
   Группы раскладываются в исходном порядке, поэтому сортировка устойчива и
   при равных частотах сохраняется возрастание значений из шага 2.
4. Каждое значение печатается столько раз, какова его частота.

Время: O(n log n) — начальная сортировка; сбор групп, сортировка подсчётом
по частоте (O(g + n), g ≤ n) и вывод — O(n).
Память: O(n) — массив, массивы групп v, f, order и счётчики count, start размера n + 1.
