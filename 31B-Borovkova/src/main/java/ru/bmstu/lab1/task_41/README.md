# Задача 41. Удаление элемента

Идея: массив сохраняется, так как x вводится после него. Затем два указателя:
i просматривает все элементы, а k — количество уже оставленных. Каждый элемент,
не равный x, переписывается на позицию k, и k увеличивается; элементы, равные x,
просто пропускаются. В конце ответ — первые k элементов массива в исходном порядке.
Удаление выполняется на месте, без нового массива и без сдвига хвоста
при каждом удалении (такой сдвиг дал бы O(n²) в худшем случае).
Если все элементы равны x, печатается пустая строка.

Время: O(n) — один проход, каждый элемент переписывается не больше одного раза.
Память: O(n) на сам массив; дополнительно O(1).
