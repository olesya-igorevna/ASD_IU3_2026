# Задача 21. K-й наименьший элемент

Идея: по требованию условия массив сортируется по неубыванию,
и ответом служит элемент с индексом k − 1 (индексация с нуля).
Повторяющиеся значения считаются отдельно: в массиве 1 2 2 3
второй и третий наименьшие элементы оба равны 2.
Перед сортировкой проверяется 1 ≤ k ≤ n, иначе индекс k − 1 вышел бы за границы массива.
Для сортировки используется Arrays.sort — условие не требует писать её вручную.

Время: O(n log n) — сортировка; чтение и выбор элемента — O(n) и O(1).
(Без требования сортировки можно было бы использовать quickselect за O(n) в среднем.)
Память: O(n) — хранится массив.
