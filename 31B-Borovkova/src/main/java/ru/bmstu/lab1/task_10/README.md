# Задача 10. Поиск элемента с условием

Идея: массив сохраняется, так как k вводится после него.
Затем массив просматривается с начала до конца; при каждом элементе,
кратном k (остаток a[i] % k равен 0), его индекс запоминается.
После прохода в переменной остаётся индекс последнего такого элемента.
Флаг found отличает случай «ничего не найдено» (вывод -1).
Перед проходом проверяется k ≠ 0, иначе деление на ноль вызвало бы ошибку.

Время: O(n) — чтение массива и один полный проход.
(Можно идти с конца и остановиться на первом найденном —
в лучшем случае быстрее, но в худшем тоже O(n).)
Память: O(n) — хранится массив.
