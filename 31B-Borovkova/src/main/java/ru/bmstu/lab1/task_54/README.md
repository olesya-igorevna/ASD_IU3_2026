# Задача 54. Сумма элементов на главной диагонали

Идея: на главной диагонали номер строки равен номеру столбца (i == j).
Матрица не хранится: каждый элемент читается и, если i == j,
сразу прибавляется к сумме. Остальные элементы читаются только
для проверки корректности ввода. Сумма хранится в long,
чтобы избежать переполнения int.

Время: O(n²) — нужно прочитать все n·n элементов матрицы.
Память: O(1) — хранятся только n, текущий элемент и сумма,
независимо от размера матрицы.
