# Задача 14. Сортировка вставками

Идея: левая часть массива a[0..i-1] всегда отсортирована по невозрастанию.
Очередной элемент x = a[i] запоминается, затем все элементы слева,
которые меньше x, сдвигаются на одну позицию вправо, а x записывается
на освободившееся место. Сравнение строгое (a[j] < x), поэтому равные
элементы не переставляются и лишних сдвигов нет.
Встроенные функции сортировки не используются.

Время: O(n²) в худшем случае (массив отсортирован по возрастанию —
каждый элемент сдвигается в самое начало, n(n - 1) / 2 сдвигов);
O(n) в лучшем случае (массив уже отсортирован по невозрастанию — сдвигов нет).
Память: O(n) — хранится массив; сортировка на месте, O(1) дополнительно.
