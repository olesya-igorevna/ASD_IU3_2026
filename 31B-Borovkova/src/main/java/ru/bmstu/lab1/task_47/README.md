# Задача 47. Поворот массива на 90 градусов

Идея: при повороте на 90° по часовой стрелке матрица n x m превращается в m x n,
и строка i результата — это столбец i исходной матрицы, прочитанный снизу вверх:

r[i][j] = a[n − 1 − j][i],  0 ≤ i < m, 0 ≤ j < n.

Пример: 1 2 3 / 4 5 6 (2 x 3) → 4 1 / 5 2 / 6 3 (3 x 2).

Матрица n x m читается целиком (поворот нельзя начать, пока не прочитана
последняя строка — она становится первым столбцом результата). Отдельная матрица
результата не создаётся: элементы печатаются сразу по формуле в нужном порядке.
Для неквадратной матрицы поворот на месте невозможен — меняется форма.

Время: O(n·m) — каждый элемент читается и печатается один раз.
Память: O(n·m) — хранится исходная матрица; дополнительно O(1).
