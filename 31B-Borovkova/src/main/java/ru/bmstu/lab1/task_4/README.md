# Задача 4. Все индексы элемента

Идея: массив сохраняется целиком, так как x вводится после него.
Затем массив просматривается слева направо, и индекс каждого элемента,
равного x, сразу печатается. Порядок возрастания получается сам собой,
потому что индексы перебираются от меньшего к большему.
Если совпадений нет, печатается -1.

Время: O(n) — чтение массива и один полный проход по нему.
Память: O(n) — хранится массив из n элементов
(индексы не сохраняются, а печатаются сразу).
