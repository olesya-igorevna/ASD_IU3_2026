# Задача 8. Фильтрация по знаку

Идея: массив читается целиком, затем один проход раскладывает элементы
в два списка ArrayList: положительные и отрицательные. Нули пропускаются.
Порядок сохраняется, потому что элементы перебираются слева направо
и добавляются в конец списка.

ArrayList выбран, потому что заранее неизвестно, сколько будет
положительных и отрицательных элементов: список сам увеличивает размер.
Добавление в конец — O(1) в среднем (амортизированно).

Время: O(n) — чтение массива и один проход по нему.
Память: O(n) — массив и два списка, вместе не больше 2n элементов.
