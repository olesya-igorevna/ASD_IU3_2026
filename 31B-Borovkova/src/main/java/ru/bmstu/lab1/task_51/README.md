# Задача 51. Максимум в каждой строке

Идея: заводится массив rowMax из n элементов — по максимуму на строку.
Матрица читается по строкам и не хранится: первый элемент каждой строки
становится её начальным максимумом, а каждый следующий элемент
сравнивается с ним и при необходимости заменяет его. Начинать с 0 нельзя:
если все числа строки отрицательные, ответ оказался бы неверным.
Ответ печатается только после чтения всей матрицы, чтобы при ошибке
ввода не успела напечататься часть результата.

Время: O(n·m) — каждый элемент читается и сравнивается один раз.
Память: O(n) — хранится только массив максимумов строк,
сама матрица не хранится.
