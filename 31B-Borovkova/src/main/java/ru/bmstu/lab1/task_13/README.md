# Задача 13. Сортировка выбором

Идея: массив делится на отсортированную часть (слева) и неотсортированную (справа).
На шаге i среди элементов a[i..n-1] ищется индекс минимального,
и этот минимум меняется местами с a[i]. После шага i первые i + 1 элементов
стоят на своих местах. Обмен делается, только если минимум не стоит уже на месте i.
Встроенные функции сортировки не используются.

Время: O(n²) — на шаге i выполняется n - 1 - i сравнений,
всего n(n - 1) / 2 сравнений при любых входных данных; обменов не больше n - 1.
Память: O(n) — хранится массив; сама сортировка выполняется на месте, O(1) дополнительно.
