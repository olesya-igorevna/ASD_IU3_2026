# Задача 37. Разворот массива

Идея: два указателя — i с начала и j с конца. Элементы a[i] и a[j] меняются
местами через временную переменную, после чего i сдвигается вправо, а j влево.
Цикл идёт, пока i < j, то есть до середины массива: каждая пара симметричных
элементов меняется ровно один раз. При нечётном n средний элемент остаётся на месте.
Новый массив не создаётся — разворот выполняется на месте, как требует условие.

Время: O(n) — чтение, n / 2 обменов и вывод.
Память: O(n) — хранится сам массив; дополнительно O(1) (индексы и одна временная переменная).
