# Задача 38. Циклический сдвиг влево

Идея: тройной разворот. Сначала k заменяется на k mod n — сдвиг на n позиций
возвращает массив в исходное состояние, поэтому учитывается только остаток
(это же позволяет k быть больше n). Массив мысленно делится на две части:
A = a[0..k−1] (уходит в конец) и B = a[k..n−1] (переходит в начало).
1. Разворачиваем A: [A' B].
2. Разворачиваем B: [A' B'].
3. Разворачиваем весь массив: (A' B')' = B A — это и есть сдвиг влево на k.

Пример: 1 2 3 4 5, k = 2 → 2 1 | 5 4 3 → 3 4 5 1 2.

Разворот отрезка выполняется на месте обменами (метод reverse), поэтому
дополнительный массив не нужен. Отрицательное k считается ошибкой ввода.

Время: O(n) — каждый элемент участвует в двух разворотах, всего ≤ n обменов.
Память: O(n) на сам массив; дополнительно O(1) — только индексы и временная переменная.
