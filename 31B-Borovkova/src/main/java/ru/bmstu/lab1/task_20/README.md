# Задача 20. Сортировка подсчётом

Идея: при чтении находятся минимум min и максимум max массива.
Заводится массив счётчиков count длины k = max − min + 1, где count[v − min] —
сколько раз встречается значение v (сдвиг на min позволяет сортировать
и отрицательные числа). Один проход по массиву заполняет счётчики,
затем значения выписываются обратно в массив по возрастанию —
каждое столько раз, сколько оно встретилось. Сравнений элементов нет.

Ограничение: массив счётчиков имеет размер диапазона значений, поэтому
диапазон k ограничен константой MAX_RANGE = 10^6; при большем разбросе
выводится ошибка (для чисел во всём диапазоне int понадобилось бы 2^32 счётчиков ≈ 16 ГБ).
Разность max − min считается в long, чтобы не было переполнения int.

Время: O(n + k) — поиск min/max и подсчёт за O(n), проход по счётчикам за O(k).
Память: O(n + k) — исходный массив и массив счётчиков.
