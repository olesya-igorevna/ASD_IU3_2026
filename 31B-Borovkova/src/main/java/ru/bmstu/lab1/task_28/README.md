# Задача 28. Медиана массива

Идея: массив сортируется по неубыванию (Arrays.sort).
- При нечётном n медиана — элемент посередине, a[n / 2]; печатается как целое число.
- При чётном n медиана — среднее двух центральных элементов a[n / 2 − 1] и a[n / 2];
  печатается как число с плавающей точкой с одним знаком после точки (2.5, 3.0, −0.5).

Детали:
- сумма двух центральных элементов считается в long, так как сумма двух int
  может выйти за предел int (2147483647 + 2147483647);
- среднее двух целых всегда либо целое, либо оканчивается на .5, а сумма по модулю
  не больше 2^32, поэтому s / 2.0 точно представимо в double и формат "%.1f" ничего не округляет;
- формат вызывается с Locale.ROOT, иначе в русской локали вместо точки была бы запятая.

Время: O(n log n) — сортировка; выбор центральных элементов — O(1).
(Медиану можно найти и за O(n) в среднем через quickselect, но сортировка проще.)
Память: O(n) — хранится массив.
