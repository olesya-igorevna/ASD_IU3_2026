# Задача 1. Максимум и минимум

Идея: числа читаются по одному; каждое сравнивается с текущими min и max.
Массив целиком не хранится — он не нужен для ответа.

Время: O(n) — каждое из n чисел читается и сравнивается один раз.
Память: O(1) — хранятся только n, min, max и текущее число,
независимо от длины массива.
