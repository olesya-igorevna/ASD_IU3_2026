# Задача 59. Определитель матрицы 3×3

Идея: определитель считается разложением по первой строке:
каждый элемент первой строки умножается на определитель 2×2
из оставшихся строк и столбцов, знаки чередуются (+, −, +).

Элементы хранятся в long, а по модулю ограничены 10^6:
тогда произведение трёх элементов не больше 10^18
и вся формула гарантированно помещается в long без переполнения.

Время: O(1) — размер матрицы фиксирован (3×3), выполняется
постоянное число операций: 9 чтений, 12 умножений, 5 сложений/вычитаний.
Память: O(1) — хранятся ровно 9 чисел.
