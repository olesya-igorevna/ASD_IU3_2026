# Задача 58. Заполнение матрицы змейкой

Идея: строки заполняются по очереди числами 1, 2, 3, ...
Чётные строки (0, 2, ...) — слева направо, нечётные (1, 3, ...) —
справа налево. Чётность строки определяется остатком i % 2.
Затем матрица печатается построчно.

Время: O(n·m) — каждая клетка заполняется один раз и печатается один раз.
Это линейная сложность от размера результата: быстрее нельзя,
так как нужно вывести все n·m чисел.
Память: O(n·m) — хранится матрица n×m.
