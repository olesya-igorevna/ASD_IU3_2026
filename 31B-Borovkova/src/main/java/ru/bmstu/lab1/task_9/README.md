# Задача 9. Проверка отсортированности

Идея: массив неубывающий, если каждый элемент не меньше предыдущего.
Поэтому достаточно сравнить все соседние пары a[i] и a[i + 1].
Флаг (boolean) изначально true; при первой паре, где следующий элемент
меньше предыдущего, он становится false и цикл прерывается (break) —
дальше проверять незачем.

Время: O(n) — в худшем случае (массив отсортирован) проверяются
все n - 1 пар; при раннем нарушении цикл завершается раньше.
Память: O(n) — хранится массив. Можно сократить до O(1),
если сравнивать каждое новое число с предыдущим прямо при чтении.
