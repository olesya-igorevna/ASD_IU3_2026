# Задача 40. Удаление дубликатов

Идея: два указателя в одном массиве. Указатель i просматривает все элементы,
а k — длина уже готовой части без дубликатов a[0..k−1] (первый элемент
всегда остаётся, поэтому k начинается с 1).
Так как массив отсортирован, все равные значения стоят подряд, и повтор
всегда равен последнему записанному элементу a[k − 1]. Если a[i] от него
отличается, это новое значение — оно записывается в a[k], и k увеличивается.
В конце ответ — первые k элементов того же массива; порядок сохраняется,
новый массив не создаётся.

При чтении проверяется, что массив действительно неубывающий: для
неотсортированного массива такой способ оставил бы несоседние повторы.

Время: O(n) — один проход, каждый элемент сравнивается и записывается не больше одного раза.
Память: O(n) на сам массив; дополнительно O(1) — только указатели.
