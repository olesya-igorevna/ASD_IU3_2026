# Задача 35. Префиксные суммы

Формат ввода: n, затем n чисел, затем q — количество запросов, затем q пар l r.
Ответ на каждый запрос печатается на отдельной строке.

Идея: при чтении массива сразу строится массив префиксных сумм p длины n + 1:
p[0] = 0, p[i + 1] = p[i] + a[i], то есть p[i] — сумма первых i элементов.
Тогда сумма на отрезке [l, r] равна

a[l] + … + a[r] = p[r + 1] − p[l]

и считается одним вычитанием. Лишний элемент p[0] = 0 избавляет от отдельного
случая l = 0. Сам исходный массив после этого не нужен и не хранится.

Проверки: количество запросов 1 ≤ q < 10^5, в каждом запросе 0 ≤ l ≤ r < n,
иначе выводится ошибка. Ответы копятся в массив и печатаются после чтения
всех запросов, чтобы при ошибке в середине не было частичного вывода.
Префиксные суммы хранятся в long — они по модулю до n · 2^31.

Время: O(n) на предпосчёт префиксных сумм + O(1) на каждый запрос,
всего O(n + q).
Память: O(n + q) — массив префиксных сумм и массив ответов.
