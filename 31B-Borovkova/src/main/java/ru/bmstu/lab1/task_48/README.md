# Задача 48. Транспонирование матрицы

Идея: при транспонировании элемент a[i][j] переходит на место a[j][i],
то есть меняются местами элементы, симметричные относительно главной диагонали.
Поэтому новый массив не нужен: достаточно обменять каждую такую пару через
временную переменную t. Перебираются только элементы над диагональю
(j от i + 1), иначе каждая пара поменялась бы дважды и матрица осталась бы
прежней. Элементы на диагонали (i = j) остаются на месте.

Время: O(n²) — чтение и печать n² элементов, n(n-1)/2 обменов.
Память: O(1) дополнительной — кроме самой входной матрицы (O(n²))
хранится только переменная t, новый массив не создаётся.
