# Задача 18. Сортировка только чётных

Идея: при чтении считается количество чётных элементов k.
Затем все чётные элементы выписываются в отдельный массив e длины k
и сортируются. После этого исходный массив проходится ещё раз,
и на каждую позицию, где стоял чётный элемент, по очереди записывается
следующий элемент из отсортированного e. Нечётные элементы не трогаются
и остаются на своих местах. Чётность проверяется как a[i] % 2 == 0 —
это верно и для отрицательных чисел (у нечётного отрицательного остаток −1).

Время: O(n log n) — сортировка k ≤ n чётных элементов; остальные проходы — O(n).
Память: O(n) — исходный массив и массив чётных элементов.
