# Задача 57. Спиральный обход матрицы

Идея: хранятся четыре границы ещё не обойдённой части матрицы
(top, bottom, left, right). Один виток спирали: верхняя строка
слева направо, правый столбец сверху вниз, нижняя строка справа
налево, левый столбец снизу вверх; после каждой стороны соответствующая
граница сдвигается внутрь. Проверки top <= bottom и left <= right
перед нижней строкой и левым столбцом не дают пройти одну и ту же
строку или столбец дважды, когда в центре остаётся полоска.

Время: O(n·m) — каждый элемент записывается в результат ровно один раз,
и результат печатается один раз.
Память: O(n·m) — матрица и массив с результатом обхода.
