# Задача 25. Сумма элементов

Идея: массив не хранится — каждое прочитанное число сразу прибавляется к сумме s.
Сумма хранится в long: по модулю она не больше n · 2^31 < 10^5 · 2^31 < 2^48,
что намного меньше предела long (2^63), а в int (2^31) она бы не поместилась
уже при двух больших числах.
Ответ печатается только после чтения всех чисел, поэтому при ошибке ввода
частичная сумма не выводится.

Время: O(n) — каждое число читается и прибавляется один раз.
Память: O(1) — хранится только сумма, массив не нужен.
