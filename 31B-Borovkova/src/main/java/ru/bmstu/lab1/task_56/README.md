# Задача 56. Умножение матриц

Идея: умножение по определению — элемент C[i][j] равен сумме
произведений i-й строки A на j-й столбец B. Три вложенных цикла:
по строкам A (n), по столбцам B (k) и по общей размерности (m).
Перед умножением проверяется, что число столбцов A равно числу строк B.
Произведения считаются в long (приведение типа до умножения),
элементы ограничены по модулю 10^6, поэтому переполнения нет.
Чтение размеров и матриц вынесено во вспомогательные методы,
чтобы не дублировать проверки для двух матриц.

Время: O(n·m·k) — для каждой из n·k клеток C выполняется m умножений.
Соответствует требованию условия.
Память: O(n·k) дополнительно — матрица результата C.
Матрицы A и B — входные данные, O(n·m + m·k).
