# Задача 30. Дисперсия

Формула (в условии не приведена, взято стандартное определение выборочной дисперсии):

D = (1/n) · Σ (a_i − x̄)^2,  где x̄ = (1/n) · Σ a_i — среднее арифметическое.

(Если нужна исправленная, несмещённая дисперсия s^2, достаточно делить
не на n, а на n − 1 — одна строка в коде.)

Идея: два прохода.
1. При чтении считается сумма элементов (в long, чтобы не переполнить int)
   и по ней — среднее x̄.
2. Второй проход складывает квадраты отклонений (a_i − x̄)^2, результат делится на n.

Почему не формула D = (Σa_i^2)/n − x̄^2 за один проход: при больших и близких
друг к другу числах она вычитает два почти равных огромных числа и теряет
точность в double (может даже получиться отрицательная «дисперсия»).
Два прохода через отклонения от среднего численно устойчивее.
Ответ печатается с 6 знаками после точки; Locale.ROOT гарантирует точку как разделитель.

Время: O(n) — два прохода по массиву.
Память: O(n) — массив хранится, потому что для второго прохода нужно уже готовое среднее.
