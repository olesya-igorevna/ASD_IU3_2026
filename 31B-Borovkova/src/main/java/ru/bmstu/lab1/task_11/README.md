# Задача 11. Ближайший к среднему

Идея: массив сохраняется, так как среднее известно только после чтения
всех чисел. Первый проход считает сумму (в long, чтобы избежать
переполнения), затем среднее вычисляется как дробное число:
сумма приводится к double до деления, иначе деление было бы целочисленным
и дробная часть среднего потерялась бы.
Второй проход ищет индекс элемента с наименьшим расстоянием
|a[i] - среднее|. Сравнение строго «меньше» сохраняет первый по индексу
элемент при одинаковых расстояниях.

Точность: сумма по модулю не больше ~2·10^14, а double хранит целые
числа точно до 2^53 ≈ 9·10^15, поэтому среднее вычисляется без потерь.

Время: O(n) — чтение массива и два прохода по нему.
Память: O(n) — хранится массив.
