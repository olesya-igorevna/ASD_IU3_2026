# Задача 6. Элементы больше среднего

Идея: массив сохраняется, так как среднее известно только после
чтения всех чисел. Первый проход считает сумму (в long, чтобы
избежать переполнения), затем вычисляется среднее sum / n
(по условию делится нацело). Второй проход считает элементы,
строго большие среднего.

Время: O(n) — чтение и два прохода по массиву, всего около 3n шагов.
Память: O(n) — хранится массив из n элементов.
