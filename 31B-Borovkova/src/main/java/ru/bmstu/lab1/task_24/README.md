# Задача 24. Чётно-нечётная сортировка

Идея: при чтении считается количество чётных элементов k.
Затем элементы раскладываются в два массива: e — чётные (длина k),
o — нечётные (длина n − k). Оба массива сортируются по возрастанию (Arrays.sort).
Ответ собирается в исходный массив: сначала e по порядку (по возрастанию),
потом o, прочитанный с конца (то есть по убыванию).
Чётность проверяется как a[i] % 2 == 0 — это верно и для отрицательных
чисел (у нечётного отрицательного остаток −1, а не 1).

Время: O(n log n) — сортировка двух частей суммарной длины n;
раскладка, сборка и вывод — O(n).
Память: O(n) — исходный массив и массивы чётных и нечётных (суммарно n элементов).
