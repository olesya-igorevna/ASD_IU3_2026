# Задача 39. Циклический сдвиг вправо

Идея: k может быть больше n. Сдвиг на n позиций возвращает массив в исходное
состояние, поэтому сдвиг на k равносилен сдвигу на k mod n (например, при n = 3
сдвиг на 7 — то же, что сдвиг на 1). После этого 0 ≤ k < n.

Сам сдвиг делается тройным разворотом на месте. Массив = [A B], где B — последние
k элементов (они должны оказаться в начале):
1. разворачиваем весь массив: [B' A'];
2. разворачиваем первые k элементов: [B A'];
3. разворачиваем оставшиеся: [B A] — это и есть сдвиг вправо на k.

Пример: 1 2 3 4 5, k = 2 → 5 4 3 2 1 → 4 5 | 3 2 1 → 4 5 1 2 3.

Без взятия остатка при k ≥ n индексы разворотов вышли бы за границы массива.
Отрицательное k считается ошибкой ввода.

Время: O(n) — каждый элемент участвует в двух разворотах; от величины k время не зависит.
Память: O(n) на сам массив; дополнительно O(1).
