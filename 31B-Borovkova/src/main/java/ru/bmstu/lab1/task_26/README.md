# Задача 26. Произведение элементов

Идея: само произведение огромно (до (2^31)^n), поэтому хранится только его остаток
от деления на MOD = 10^9 + 7. Используется свойство (p · x) mod M = ((p mod M) · (x mod M)) mod M:
после каждого умножения берётся остаток, и p всегда остаётся в пределах [0, MOD).
Каждый множитель тоже сначала приводится к [0, MOD): в Java остаток отрицательного
числа отрицательный (−5 % MOD = −5), поэтому к нему прибавляется MOD.
Так ответ для отрицательного произведения получается стандартным неотрицательным
остатком (например, −5 → 1000000002).
Оба множителя меньше 10^9 + 7, поэтому их произведение не больше (10^9 + 6)^2 ≈ 1.0·10^18,
что меньше предела long ≈ 9.2·10^18 — переполнения нет.
Массив не хранится — числа обрабатываются сразу при чтении.

Время: O(n) — одно умножение и одно взятие остатка на элемент.
Память: O(1) — хранится только текущий остаток произведения.
