# Задача 7. Второй максимум

Идея: массив не хранится. Числа читаются по одному, при этом
поддерживаются два значения: one (максимум) и two (второй максимум).
Если число больше one — старый максимум становится вторым, а число
новым максимумом; иначе, если число больше two, оно становится новым
вторым. Изначально two = Integer.MIN_VALUE (наименьший int), чтобы
его заменило первое же подходящее число.

Время: O(n) — каждое число читается и сравнивается один раз.
Память: O(1) — хранятся только n, one, two и текущее число.
