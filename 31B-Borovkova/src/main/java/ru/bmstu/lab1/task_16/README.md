# Задача 16. Сортировка по модулю

Идея: каждое число x заменяется ключом k = 2·|x|, если x < 0, и k = 2·|x| + 1, если x ≥ 0.
Сравнение ключей даёт ровно нужный порядок: ключи сначала упорядочены по модулю,
а при равном модуле у отрицательного числа ключ на 1 меньше, чем у положительного.
Ключи сортируются обычной сортировкой чисел (Arrays.sort для long[]),
затем число восстанавливается: модуль равен k / 2, а чётный ключ означает отрицательное число.
Ключи хранятся в long, потому что |−2 147 483 648| не помещается в int.
Равные числа дают равные ключи, поэтому устойчивость сортировки не требуется.

Время: O(n log n) — сортировка n ключей; построение ключей и вывод — O(n).
Память: O(n) — массив ключей.
