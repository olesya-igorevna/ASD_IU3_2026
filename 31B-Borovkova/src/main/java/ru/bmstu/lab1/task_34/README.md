# Задача 34. Максимальная сумма подмассива

Идея: алгоритм Кадане. Для каждой позиции i поддерживается cur — максимальная
сумма непрерывного подмассива, который заканчивается ровно на a[i]:

cur_i = max(a[i], cur_{i−1} + a[i]).

То есть подмассив либо продолжается (если накопленная сумма cur_{i−1} не отрицательна —
она только увеличит результат), либо начинается заново с a[i] (если cur_{i−1} < 0,
она только уменьшила бы сумму). Ответ best — максимум cur по всем позициям.

Подмассив должен быть непустым, поэтому cur и best инициализируются первым элементом,
а не нулём: если все числа отрицательные, ответ — наибольшее из них (а не 0).
Суммы хранятся в long — они по модулю до n · 2^31 и в int не помещаются.
Массив не хранится — числа обрабатываются сразу при чтении.

Время: O(n) — один проход, O(1) действий на элемент.
Память: O(1) — хранятся только cur и best.
