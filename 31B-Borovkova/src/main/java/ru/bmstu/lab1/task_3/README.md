# Задача 3. Подсчёт вхождений

Идея: массив сохраняется целиком, так как число x вводится после него.
Затем массив просматривается полностью, и счётчик увеличивается
на каждом элементе, равном x. В отличие от задачи 2, поиск нельзя
прервать досрочно: нужно найти все вхождения, а не первое.

Время: O(n) — чтение массива n шагов и полный проход по нему ещё n шагов.
Память: O(n) — хранится массив из n элементов.
