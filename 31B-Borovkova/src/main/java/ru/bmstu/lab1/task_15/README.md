# Задача 15. Пузырьковая сортировка с подсчётом обменов

Идея: на каждом проходе соседние элементы сравниваются попарно, и если левый
больше правого, они меняются местами, а счётчик обменов увеличивается.
После прохода i самый большой из оставшихся элементов оказывается на позиции
n - 1 - i, поэтому следующий проход на один элемент короче.
Досрочный выход: если за весь проход не было ни одного обмена, массив уже
отсортирован и сортировка прекращается. Сравнение строгое, поэтому равные
элементы не меняются и не учитываются в счётчике.
Количество обменов равно числу инверсий массива и может достигать
n(n - 1) / 2 ≈ 5·10^9, поэтому счётчик хранится в long.

Время: O(n²) в худшем случае (массив отсортирован по убыванию — n - 1 полных проходов);
O(n) в лучшем случае (массив уже отсортирован — один проход без обменов и выход).
Память: O(n) — хранится массив; сортировка на месте, O(1) дополнительно.
