# Задача 46. Сжатие диапазона

Идея: сжатие координат.
1. Делается копия массива b и сортируется (Arrays.sort).
2. Из b на месте удаляются повторы (как в задаче 40: двумя указателями),
   в начале остаются k различных значений b[0..k−1] по возрастанию.
3. Ранг элемента — это его индекс в b[0..k−1]: сколько различных значений меньше него.
   Он находится бинарным поиском (Arrays.binarySearch по отрезку [0, k)),
   элемент там гарантированно есть, поэтому результат всегда неотрицательный.

Пример: 100 50 100 300 → различные значения 50 100 300 → ранги 1 0 1 2.

Время: O(n log n) — сортировка копии и n бинарных поисков по O(log n);
удаление повторов — O(n).
Память: O(n) — исходный массив (в него же записываются ранги) и отсортированная копия.
