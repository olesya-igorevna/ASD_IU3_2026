# Задача 5. Сумма элементов на чётных позициях

Идея: массив сохраняется, затем цикл с шагом 2 (i = 0, 2, 4, ...)
складывает только элементы с чётными индексами — нечётные даже
не просматриваются. Сумма хранится в long, чтобы избежать
переполнения int при сложении больших чисел.

Время: O(n) — чтение массива n шагов и проход по половине элементов
(n/2 шагов, константа 1/2 в асимптотике не учитывается).
Память: O(n) — хранится массив из n элементов.
