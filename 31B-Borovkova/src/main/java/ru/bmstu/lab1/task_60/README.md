# Задача 60. Острова из единиц

Идея: матрица просматривается по клеткам. Каждая единица, в которой
мы ещё не были, — начало нового острова: счётчик увеличивается,
и обход в ширину (BFS) отмечает посещёнными все единицы этого острова,
двигаясь только по горизонтали и вертикали. Благодаря отметкам
ни один остров не считается дважды.

Почему BFS через очередь на массивах, а не рекурсивный DFS:
рекурсия на большом острове (до 10^6 клеток) может переполнить стек,
а очередь работает при любом размере острова.

Время: O(n·m) — каждая клетка попадает в очередь не больше одного раза,
и у каждой проверяются 4 соседа; плюс один проход по всей матрице.
Память: O(n·m) — матрица, отметки посещения и очередь, каждое размера n·m.
