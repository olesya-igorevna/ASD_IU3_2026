# Задача 31. Скалярное произведение

Идея: скалярное произведение a · b = a_0·b_0 + a_1·b_1 + … + a_{n−1}·b_{n−1}.
Длина n вводится один раз, затем два массива по n чисел.
Первый массив сохраняется, а второй не хранится: каждое b_i сразу
умножается на a_i и прибавляется к сумме.

Переполнение: одно произведение a_i · b_i считается в long — по модулю оно
не больше 2^31 · 2^31 = 2^62 и помещается. А сумма уже двух таких произведений
может достичь 2^63 и выйти за предел long; всего сумма бывает до n · 2^62 ≈ 2^79.
Поэтому сумма накапливается в BigInteger (числа не длиннее ~80 бит, сложение за O(1)).

Время: O(n) — одно умножение и одно сложение на пару элементов.
Память: O(n) — хранится только первый массив.
