# Задача 29. Мода массива

Идея: массив сортируется по неубыванию (Arrays.sort), после чего равные
элементы стоят подряд сериями, а сами серии идут по возрастанию значения.
Одним проходом считается длина текущей серии k: если элемент равен предыдущему,
k увеличивается, иначе начинается новая серия с k = 1.
Как только длина серии строго превышает лучшую найденную, запоминается
значение этой серии. Из-за строгого сравнения при равной частоте остаётся
серия, найденная раньше, — то есть с меньшим значением, как требует условие.

Ограничения по условию: 1 ≤ n ≤ 10^4 (в этой задаче допускается n = 1).

Время: O(n log n) — сортировка; подсчёт серий — O(n).
(Можно за O(n) в среднем с HashMap значение → частота, но тогда для выбора
наименьшего из равных пришлось бы дополнительно сравнивать значения.)
Память: O(n) — хранится массив.
