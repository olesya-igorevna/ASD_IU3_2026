# Задача 23. Проверка анаграммы массивов

Идея: массив b является перестановкой массива a тогда и только тогда,
когда в них одни и те же значения с одними и теми же количествами повторений.
Это равносильно тому, что после сортировки массивы совпадают поэлементно.
Оба массива сортируются (Arrays.sort), затем сравниваются по индексам;
при первом несовпадении флаг f сбрасывается и цикл прерывается.
Длина у обоих массивов одна (n вводится один раз), как требует условие.

Время: O(n log n) — сортировка двух массивов; сравнение — O(n).
(Альтернатива — подсчёт количеств в HashMap за O(n) в среднем,
но с дополнительной памятью под таблицу.)
Память: O(n) — два массива; сортировка на месте.
