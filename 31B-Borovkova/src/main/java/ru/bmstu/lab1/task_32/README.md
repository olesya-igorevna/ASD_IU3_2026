# Задача 32. Сумма произведений пар

Идея: перебор всех пар i < j занял бы O(n²). Вместо этого сумма группируется
по второму элементу пары:

Σ_{i<j} a_i · a_j = Σ_j a_j · (a_0 + a_1 + … + a_{j−1}) = Σ_j a_j · p_j,

где p_j — сумма всех элементов перед a_j. Эта сумма p поддерживается на ходу:
для очередного числа x к ответу прибавляется x · p, а затем x добавляется к p.
Массив при этом не хранится — числа обрабатываются сразу при чтении.

Пример: 1 2 3 → 2·1 + 3·(1 + 2) = 2 + 9 = 11 = 1·2 + 1·3 + 2·3.

Переполнение: p по модулю не больше n · 2^31 < 2^48 и помещается в long,
но произведение x · p бывает до 2^79, а итог — до n² / 2 · 2^62 ≈ 2^94,
это больше предела long (2^63). Поэтому произведение и сумма считаются в BigInteger.
Длина чисел ограничена (~100 бит), так что каждая операция с ними — O(1).

(Другой вариант той же асимптотики: ((Σa)² − Σa²) / 2.)

Время: O(n) — по одному умножению и двум сложениям на элемент, без перебора пар.
Память: O(1) — хранятся только p и текущая сумма.
