# Задача 19. Объединение двух отсортированных массивов

Идея: метод двух указателей (как шаг слияния в сортировке слиянием).
Указатель i идёт по массиву a, указатель j — по массиву b. На каждом шаге
меньший из a[i] и b[j] записывается в ответ, и сдвигается указатель
того массива, откуда он взят. При равенстве берётся элемент из a.
Когда один массив заканчивается, остаток другого дописывается в конец —
он уже отсортирован и не меньше всего записанного ранее.
При чтении проверяется, что каждый массив действительно неубывающий
(иначе слияние дало бы неотсортированный результат) — на это выводится ошибка.
Чтение массива с проверками вынесено в метод readSortedArray,
так как одинаково выполняется для обоих массивов.

Время: O(n + m) — каждый элемент читается, проверяется и записывается в ответ ровно один раз.
Память: O(n + m) — два исходных массива и массив-результат.
