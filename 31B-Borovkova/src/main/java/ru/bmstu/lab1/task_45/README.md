# Задача 45. Разбиение по опорному элементу

Идея: трёхчастное разбиение Дейкстры («задача о голландском флаге») за один проход.
Поддерживаются три указателя и инвариант:
- a[0..lt−1] — элементы меньше p;
- a[lt..i−1] — элементы, равные p;
- a[i..gt] — ещё не просмотренные;
- a[gt+1..n−1] — элементы больше p.

На каждом шаге смотрим на a[i]:
- a[i] < p — меняем его с a[lt] (там стоит элемент, равный p, или он сам),
  сдвигаем lt и i;
- a[i] > p — меняем его с a[gt] и уменьшаем gt; i не сдвигаем, потому что
  пришедший с конца элемент ещё не проверен;
- a[i] = p — просто сдвигаем i.

Цикл заканчивается, когда непросмотренная часть пуста (i > gt).
Порядок внутри групп не сохраняется, что по условию допустимо.

Время: O(n) — на каждом шаге либо i растёт, либо gt уменьшается,
поэтому шагов не больше n.
Память: O(n) на сам массив; дополнительно O(1) — три индекса и временная переменная обмена.
