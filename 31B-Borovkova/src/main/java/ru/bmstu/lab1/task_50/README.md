# Задача 50. Сумма столбцов матрицы

Идея: заводится массив colSum из m элементов — по сумме на столбец.
Матрица читается по строкам и не хранится: каждый элемент сразу
прибавляется к сумме своего столбца. Начальные суммы равны 0
(новый массив в Java заполняется нулями) — для сложения это правильно,
в отличие от поиска минимума или максимума. Суммы хранятся в long,
чтобы избежать переполнения int.

Время: O(n·m) — каждый элемент читается и прибавляется один раз.
Память: O(m) — хранится только массив сумм столбцов,
сама матрица не хранится.
