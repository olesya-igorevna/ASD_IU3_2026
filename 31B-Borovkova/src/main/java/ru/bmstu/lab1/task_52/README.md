# Задача 52. Минимум в каждом столбце

Идея: заводится массив colMin из m элементов — по минимуму на столбец.
Матрица читается по строкам и не хранится: элементы первой строки
становятся начальными минимумами своих столбцов, а каждый следующий
элемент сравнивается с минимумом своего столбца и при необходимости
заменяет его. Начинать с 0 нельзя: если все числа столбца положительные,
ответ оказался бы неверным.

Время: O(n·m) — каждый элемент читается и сравнивается один раз.
Память: O(m) — хранится только массив минимумов столбцов,
сама матрица не хранится.
